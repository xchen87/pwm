# World Brief Prompt

Generate a concise briefing of meaningful changes in the user's world.

Prioritize:
1. confirmed deadlines/commitments
2. meaningful changes
3. decisions requiring attention
4. high-impact anomalies
5. useful memories

Suppress routine noise and duplicates.

For every item provide:
- what changed
- why it matters
- confidence
- source
- suggested next step, if appropriate

Do not imply a recommendation when evidence is insufficient.
